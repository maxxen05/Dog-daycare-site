# Dog-site

Så jag valde att använda mig av de vi har lärt oss från tidigare lektioner samt grupparbetet. Sidan är en fungerade hund pansionat sida där man kan se tjänster, personal, kontakta formulär samt omdömen. 

# små funktioner 

i gruppuppgiften så lärde vis oss att använda oss av hidden som vi kopplade med javaScript för att vissa en sak i taget när man väl trycker på en av våra länkar som gör att man kommer till sidans sektioner. 

# design 

Så jämförde jag med andra hund sidor och valde då att ha en logga högst upp samt en trevlig natur & hund bakgrunds bild samt namn på hund pansionatet. Vi har även en öppen just nu/ stängd just nu som uppdateras automatiskt så besökare ser om de är öppet eller inte.
